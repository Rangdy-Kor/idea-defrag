# 개인 개발자의 실무 개발 환경 선택

---

**C** | **C++** :

- **컴파일러**: Clang
- **빌드 시스템**: CMake
- **패키지 관리자**: vcpkg
- **에디터**: CLion

**C#**:

- **SDK**: .NET SDK
  - **컴파일러**: Roslyn
  - **런타임**: .NET Runtime
  - **빌드 시스템**: MSBuild
  - **패키지 관리자**: NuGet
- **에디터**: Rider

**Java**:

- **JDK**: Temurin
  - **컴파일러**: javac
  - **런타임**: HotSpot JVM
- **빌드 시스템** | **패키지 관리자**: Gradle
- **에디터**: IntelliJ IDEA

**Python**:

- **인터프리터** | **런타임**: CPython
- **프로젝트 관리자** | **패키지 관리자**:  uv
- **에디터**: VS Code

**TypeScript** | **JavaScript**:

- **컴파일러**: tsc
- **실행 환경**: Node.js
  - **런타임**: V8
- **버전 관리자**: fnm
- **패키지 관리자**:
- **에디터**: VS Code
